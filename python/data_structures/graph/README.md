# Graph

## Summary

This is an implementation of a generic graph that supports many popular graph
functions and modes of operation, including: unidirectional, bidirectional,
weighted, and unweighted graphs. There are also various algorithm
implementations.

## Install

By using the `pip`
[VCS option](https://pip.pypa.io/en/stable/topics/vcs-support/), you can
directly install the graph into whatever environment you're using.

Here's the command you can just copy

```
python -m pip install "graph @ git+https://github.com/amiel-iliesi/PSU_tutoring_materials.git#subdirectory=python/data_structures/graph"
```

```
pip install -e "git+https://github.com/amiel-iliesi/PSU_tutoring_materials.git#egg=graph&subdirectory=python/data_structures/graph"
```
