# Thoughts

Now that I finished the program I want to tell you the user that--even though I 
went through this process more slowly than I otherwise would have--and even

benefits from taking time. On top of that, the time saved avoiding bugs you

Just give it a shot and see if you can feel the same benefits I did while 
writing this guide.
